เชื่อมต่อกับ GitHub

หน้านี้อ่านประวัติจาก repo ส่วนตัวของคุณโดยตรง — ต้องใช้ token แบบอ่านอย่างเดียว ทำครั้งเดียวต่อเครื่อง

  1. เปิด github.com/settings/personal-access-tokens/new
  2. Token name: claude-history-phone · Expiration: 1 ปี
  3. Repository access: Only select repositories → เลือก claude-setup
  4. Permissions → Repository → Contents: Read-only
  5. กด Generate token แล้วคัดลอกมาวางด้านล่าง

token เก็บไว้ในเบราว์เซอร์นี้เท่านั้น ส่งไปที่ api.github.com อย่างเดียว ยกเลิกได้ทุกเมื่อที่หน้า GitHub
