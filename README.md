# claude-history

หน้าเว็บสำหรับอ่านประวัติ Claude Code / Cowork บนมือถือ — **repo นี้มีแค่โค้ดหน้าเว็บ ไม่มีข้อมูลใดๆ**

- เปิดที่ https://bearpanda2012-wq.github.io/claude-history/
- ข้อมูลอ่านตรงจาก repo ส่วนตัว (private) ผ่าน GitHub API ด้วย token แบบอ่านอย่างเดียวที่ผู้ใช้ใส่เองในเบราว์เซอร์
- token และข้อมูลที่โหลดมาเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ถูกส่งไปที่อื่นนอกจาก `api.github.com`

ต้นฉบับของไฟล์เหล่านี้อยู่ในโฟลเดอร์ `web/` ของ repo ส่วนตัว `claude-setup` — แก้ที่นั่นแล้วคัดลอกมาที่นี่
